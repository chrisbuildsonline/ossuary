# Tasks: Warranty Wraith (`apps/warranty-wraith`)

Rules for every task: write the failing test first, then the code, and keep the whole suite green before the next task. Requirement numbers refer to `requirements.md` in this folder. Contract ids (C1.1 and so on) refer to `.kiro/specs/skeleton-contract/requirements.md`. The skeleton-contract tasks and the Pantry Reaper tasks must be done first.

All commands run from the repo root as `bun run <script>`. The app has no scripts and no vitest or Playwright config of its own. Unit tests live in `apps/warranty-wraith/src` and end-to-end tests in `apps/warranty-wraith/e2e`. Nothing in this spec copies code from `apps/pantry-reaper` into the app. Group 1 changes the core (and moves Pantry Reaper's PWA code into it), so do it first.
