# Tasks: Pantry Reaper (`apps/pantry-reaper`)

Rules for every task: write the failing test first, then the code, and keep the whole suite green before the next task. Requirement numbers refer to `requirements.md` in this folder. Contract ids (C1.1 and so on) refer to `.kiro/specs/skeleton-contract/requirements.md`. Only spec, data, theme and wiring tasks are listed, plus the core addenda in 1.1 and 6.4. The skeleton-contract tasks must be done first.

All commands run from the repo root as `bun run <script>`. The app has no scripts and no vitest or Playwright config of its own. Unit tests live in `apps/pantry-reaper/src` and end-to-end tests in `apps/pantry-reaper/e2e`.
